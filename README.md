# coinarb — арбитраж монет: staraya-moneta → NGS → meshok

Сканер, парсер и аналитика для схемы «купить сырую монету → слабировать в NGS →
продать в слабе с наценкой». Считает не «потенциал», а чистую прибыль после
слабирования, комиссий, логистики и резерва на риски.

📄 **[playbook с методикой и экономикой →](docs/PLAYBOOK.md)**

## Быстрый старт

```bash
pip install playwright beautifulsoup4 lxml
python -m playwright install chromium

python scan.py import-comps data/comps_seed.csv   # база сопоставимых цен
python scan.py harvest-sm                         # собрать лоты staraya-moneta
python scan.py analyze                            # найти возможности
python scan.py report                             # отчёт в data/report.html
```

Полный цикл одной командой: `python scan.py all`

## Как это работает

```
staraya-moneta / meshok  →  нормализация  →  SQLite  →  comps + экономика  →  HTML
        сбор                  признаки        история      оценка прибыли      отчёт
```

**Нормализация.** Заголовки вроде «Рубль 1913 г. (ВС) 300 лет дома Романовых,
выпуклый чекан, в слабе ННР MS 62» превращаются в структуру: год, номинал, металл,
вес, грейдер, грейд по шкале Шелдона, разновидность. Металл восстанавливается по
справочнику с привязкой к годам — продавцы указывают его меньше чем в половине
лотов. Тесты: `python tests/test_reference.py` (17/17).

**Экономика** (`coinarb/fees.py`). Тариф NGS подбирается по рыночной стоимости
монеты, комиссия Мешка — 3% с потолком 10 000 ₽, плюс логистика, налог и резерв
на риски 15%.

**Ключевой параметр** — `ngs_discount`, скидка слаба NGS к NGC/ННР. По умолчанию
0.70, и это **гипотеза**. Пока не откалибрована по реальным парам цен, все суммы
в отчёте — сценарий, а не прогноз.

```bash
# переопределить любое допущение, не трогая код
python scan.py analyze --terms '{"ngs_discount":0.6,"risk_haircut":0.25}'
```

## Доступ к сайтам

| Сайт | Статус | Что делать |
|---|---|---|
| staraya-moneta.ru | Работает через браузер (JS-челлендж обходится) | Ничего, `harvest-sm` из коробки |
| meshok.net | Cloudflare Turnstile, из дата-центра не проходится | `--storage-state cookies.json` или `--proxy` |
| ngs.vc | Открыт | Тарифы зашиты в `fees.NGS_TARIFFS` |

Cookies Мешка: зайдите на meshok.net в своём браузере, выгрузите cookies
расширением (например, EditThisCookie) в `cookies.json`, передайте
`--storage-state cookies.json`.

## Что показали реальные данные

На staraya-moneta **0 лотов** проходят фильтр арбитража: там всё уже в слабах
NGC/ННР по верхней планке рынка. Вход осмыслен только на **сырых** монетах, а
таких в этой рознице почти нет — их нужно искать на Мешке, в регионах, на
площадках без слабов. Это ограничение рынка, а не кода.

Поэтому главный дефицит системы — не парсер, а **база проданных цен (comps)**.
Она наполняется из `data/comps_seed.csv` (сейчас демо-данные, помечены `DEMO`)
и автоматически: лоты, исчезнувшие из выдачи между прогонами, помечаются
неактивными — это прокси «продано».

## Структура

```
coinarb/
  fetch.py       Playwright-фетчер: кэш, ретраи, rate-limit, обход челленджа
  normalize.py   заголовок → структурированные признаки
  reference.py   справочник металлов/весов (с тестами)
  fees.py        тарифы NGS, комиссии, юнит-экономика сделки
  analyze.py     comps, оценка цены, скрининг, калибровка скидки NGS
  store.py       SQLite: лоты, временные ряды цен, comps, возможности
  comps_io.py    импорт comps из CSV
  report.py      автономный HTML-отчёт (инлайн-стили)
  sources/meshok.py  парсер Мешка, устойчивый к смене вёрстки
scan.py          CLI
data/            coins.db, report.html, opportunities.csv
docs/PLAYBOOK.md методика, экономика, риски
```

## Ограничения, о которых нужно знать

- Демо-comps в `comps_seed.csv` — иллюстрация механики, не рыночные данные.
- Вес и металл восстанавливаются по справочнику: для нестандартных типов
  остаются пустыми (осознанно, лучше пусто, чем неверно).
- Мешок не собирается без ваших cookies/прокси — это ограничение доступа, а не кода.
- Сбор данных в обход защиты площадки нарушает её пользовательское соглашение.
