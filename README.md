# coinarb — арбитраж монет: staraya-moneta → NGS → meshok + база сделок

Сканер, парсер и аналитика для схемы «купить сырую монету → слабировать в NGS →
продать в слабе с наценкой», плюс три дополнительных стратегии арбитража.
Оценивает прибыль после слабирования, комиссий,
логистики и резерва на риски. Оценки не гарантируют фактическую прибыль.
Живой сбор и парсеры зависят от доступности и актуальной вёрстки сайтов;
полнота данных и успешное прохождение защиты не гарантируются.

📄 **[playbook с методикой и экономикой →](docs/PLAYBOOK.md)**

## Быстрый старт

### Windows — самый простой путь (двойным кликом)

1. `SETUP.bat` — один раз: проверит Python, установит библиотеки и браузер,
   прогонит самопроверку (`scan.py demo`).
2. `RUN.bat` — каждый сбор: полный цикл; если лежит `cookies.json`, соберёт
   попытается собрать и Мешок, а в конце откроет отчёт в браузере.
   Если сбор не удался или площадка заблокировала доступ, в отчёте могут быть
   только ранее собранные данные — обязательно проверяйте сообщения в окне.

### Вручную (любая ОС)

**Установка (один раз):**

```bash
pip install -r requirements.txt                  # playwright, beautifulsoup4, lxml
python -m playwright install chromium            # браузер для сбора
python scan.py demo                              # самопроверка: всё работает?
```

### Если ничего не работает

| Симптом | Причина | Лечение |
|---|---|---|
| `No module named 'coinarb'` | Скачан СТАРЫЙ архив main (до 08.11.2026) | Скачайте архив заново: Code → Download ZIP |
| `No module named 'bs4'` / `'lxml'` | Библиотеки не установлены | `pip install -r requirements.txt` (Windows: `SETUP.bat`) |
| `'python' / 'pip' не является внутренней или внешней командой`, открывается Microsoft Store | Python не установлен или не в PATH | Установите с python.org, галочка **«Add python.exe to PATH»**, перезапустите консоль; или используйте `py -3` вместо `python` |
| `can't open file 'scan.py'` | Запускаете не из папки проекта | `cd` в распакованную папку (`coins-main`), где лежит `scan.py` |
| Окно мелькнуло и закрылось | Двойной клик по `scan.py` | Запускайте из консоли или через `SETUP.bat`/`RUN.bat` |
| Chromium не скачивается | Блокировка CDN playwright | Повторить позже; или `set PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright` и снова `python -m playwright install chromium` |
| Мешок не возвращает лоты / Cloudflare | Защита сайта, просроченные cookies или изменение сайта | Проверьте доступ в браузере и попробуйте обновить cookies; успешный сбор не гарантирован |
| Обрывки команд или кракозябры в старом `.bat` | Ошибка кодировки в старой версии скрипта | Скачайте свежий ZIP с main, распакуйте и запустите новые `SETUP.bat` и `RUN.bat` |
| `UnicodeEncodeError` при выводе в файл | Windows-кодировка при перенаправлении | `set PYTHONIOENCODING=utf-8` перед запуском |

**ПОЛНЫЙ СБОРОТ ОДНОЙ КОМАНДОЙ** (магазин SM → аукционы SM → Мешок активные
и завершённые лоты → аналитика → индекс → калибровка NGS → отчёт):

```bash
python scan.py all --storage-state cookies.json
```

Без `cookies.json` Мешок будет пропущен (Cloudflare), остальное выполнится.
Cookies: зайдите на meshok.net в своём браузере → расширение EditThisCookie →
экспорт → сохраните как `cookies.json` в папку проекта. Поддерживаются JSON-массив
EditThisCookie и Playwright storage state. Cookies дают доступ к вашему аккаунту:
не отправляйте файл другим людям и не выкладывайте его в сеть. Наличие cookies
не гарантирует обход защиты площадки.

Ручная догрузка фактов продаж из архивов аукционов (Конрос, Волмар, Редкие
Монеты): сохраните страницу архива → `python scan.py import-sold archive.html --source conros`.

**Отдельные команды:**

```bash
python scan.py harvest-sm                         # только лоты staraya-moneta
python scan.py harvest-meshok --sold --storage-state cookies.json  # завершённые лоты Мешка -> сделки
python scan.py import-comps data/comps_seed.csv   # справочные цены (демо-набор)
python scan.py renormalize                        # пересчитать признаки текущим парсером
python scan.py index                              # ценовой индекс по типам (+ CSV)
python scan.py calibrate                          # скидка NGS по реальным парам грейдеров
python scan.py analyze                            # все стратегии арбитража
python scan.py report                             # отчёт в data/report.html
python scan.py calc --buy 12000 --sale 43400      # калькулятор одной сделки
```

Без интернета/браузера работают: `import-comps`, `import-sold`, `import-raw`,
`renormalize`, `index`, `calibrate`, `analyze`, `report`, `stats`, `mark`,
`calc`, `demo`. Ежедневная рутина: просто `python scan.py all …` — история цен
и vanish-прокси сделок копятся сами.

## Как это работает

```
staraya-moneta / meshok / архивы аукционов
        │ сбор (Playwright)          │ импорт (CSV/JSON/HTML)
        ▼                            ▼
     lots + features  ◄──── нормализация ────►  deals (БАЗА СДЕЛОК)
        │                            │
        └────────► comps + индекс ◄──┘
                     │
        стратегии арбитража (4 шт.) ──► opportunities ──► HTML/CSV отчёт
```

**Нормализация.** Заголовки вроде «Рубль 1913 г. (ВС) 300 лет дома Романовых,
выпуклый чекан, в слабе ННР MS 62» превращаются в структуру: год, номинал
(канонизированный: гривенник→10 коп, полтинник→полтина…), металл, вес,
минцмейстер, грейдер, грейд по Шелдону, разновидность. Книги, банкноты, жетоны
и наборы отсекаются от монет — на реальном срезе 463 лота это дало чистые
69 монет вместо 121 «вперемешку с литературой». Тесты: `pytest tests/` (17+).

**База сделок (`deals`)** — ядро системы. Наполняется четырьмя способами:

| Способ | Команда | Достоверность |
|---|---|---|
| Завершённые аукционы Мешка (итоговая цена) | `harvest-meshok --sold` | факт продажи |
| Архивы аукционов (Конрос, Волмар, Редкие Монеты…) — CSV/JSON/HTML | `import-sold FILE` | факт продажи (hammer) |
| Лот исчез из выдачи между прогонами | автоматически при `harvest-sm` | прокси «продано» (могли снять) |
| Свои сделки / ручные записи | `import-sold` / `mark` | факт |

Универсальный HTML-парсер архивов не привязан к вёрстке: ищет в таблицах строки
«название + число-цена + дата» (примеры форматов в `data/examples/`). Повторный
импорт одного архива не дублирует сделки (дедупликация).

**Стратегии арбитража** (`coinarb/arbitrage.py`):

| Стратегия | Суть | Что нужно |
|---|---|---|
| `slab_arb` | сырая монета → NGS → продажа в слабе | comps/сделки по типу |
| `cross_source` | один тип на двух площадках с разрывом ≥12% | ≥2 источника в БД |
| `slab_flip` | признанный слаб (NGC/PCGS/ННР) ниже медианы рынка | сделки/comps ≥2 |
| `underpriced` | радар: ask ниже медианы рынка на ≥20% | comps/сделки ≥3 |

Найденные возможности хранятся в БД со статусами:
`python scan.py mark 12 --status taken|rejected|done`.

**Калькулятор сделки** (`python scan.py calc --buy 12000 --sale 43400`): полная
раскладка одной сделки — NGS, логистика, комиссия площадки, резерв на риски,
ROI и точка безубыточности. Уважает `--terms`.

**Демо-режим** (`python scan.py demo`): синтетический рынок в отдельной БД
(`data/demo.db`, отчёт `data/report_demo.html` с водяным знаком), на котором
видно, как срабатывают все четыре стратегии, как индекс считает премию слаба
и как калибровка измеряет скидку NGS по парам грейдеров. Все записи помечены
`DEMO-*` — перепутать с реальным рынком нельзя.

**Ценовой индекс** (`python scan.py index`): по каждому типу (год|номинал|металл) —
медианы сырых и слабированных листингов, **премия слаба** (измеренный рынком
приз схемы «сырая→слаб»), медиана фактических сделок, разброс ask, сколько дней
лоты висят (прокси ликвидности). Экспорт в `data/price_index.csv`.

**Калибровка скидки NGS** (`python scan.py calibrate`): ищет в БД пары «та же
монета, близкий грейд, разные грейдеры» и считает медиану отношений. DEMO-comps
из калибровки исключаются автоматически. Пока пар с NGS нет — `ngs_discount=0.70`
остаётся **гипотезой**, и отчёт это честно подсвечивает.

**Экономика** (`coinarb/fees.py`). Тариф NGS подбирается по рыночной стоимости
монеты, комиссия Мешка — 3% с потолком 10 000 ₽, плюс логистика, налог и резерв
на риски 15%. Любое допущение переопределяется без правки кода:

```bash
python scan.py analyze --terms '{"ngs_discount":0.6,"risk_haircut":0.25}'
```

## Доступ к сайтам

| Сайт | Статус | Что делать |
|---|---|---|
| staraya-moneta.ru | Магазин работает через браузер (JS-челлендж обходится) | `harvest-sm` из коробки |
| staraya-moneta.ru аукционы | **EXPERIMENTAL**: URL и разметка витрины не проверены живьём | `harvest-sm-auction`, при необходимости поправить `AUCTION_URLS` |
| meshok.net | Cloudflare Turnstile, из дата-центра не проходится | `--storage-state cookies.json` или `--proxy`; `--sold` для завершённых |
| архивы аукционов | Импорт сохранённых страниц/выгрузок | `import-sold FILE.html --source conros` |
| ngs.vc | Открыт | Тарифы зашиты в `fees.NGS_TARIFFS` |

Cookies Мешка: зайдите на meshok.net в своём браузере, выгрузите cookies
расширением (например, EditThisCookie) в `cookies.json`, передайте
`--storage-state cookies.json`.

## Что показали реальные данные (срез 463 лота staraya-moneta)

- После чистки нормализатором: **69 монет**, 58 типов в индексе, остальное —
  книги (216), банкноты (106), медали/жетоны (12), наборы (24), прочее (36).
- **0 лотов** проходят фильтр арбитража: витрина SM — это слибы NGC/ННР по
  верхней планке рынка. Лист наблюдения показывает отрицательную «прибыль»
  почти по всем позициям — вход через этот магазин невыгоден. Это ограничение
  рынка, а не кода.
- Сырых монет на SM почти нет (единицы: 5 руб 1859, 3 руб 2023, юбилейка СССР).
  Вход осмыслен на Мешке, у региональных продавцов и на площадках без слабов.
- Реальных сделок в базе пока 0, comps — демо-набор (помечен `DEMO`).
  **Главный дефицит системы — настоящие hammer-цены**: наполняйте `deals`.

## Структура

```
coinarb/
  fetch.py       Playwright-фетчер: кэш, ретраи, rate-limit, обход челленджа (ленивый импорт)
  normalize.py   заголовок → структурированные признаки (тип/год/номинал/металл/грейд)
  reference.py   справочник металлов/весов (с тестами)
  fees.py        тарифы NGS, комиссии, юнит-экономика сделки
  analyze.py     comps (сделки > справочник > листинги), оценка цены, калибровка NGS
  index.py       ценовой индекс по типам: премия слаба, спреды, ликвидность
  arbitrage.py   4 стратегии арбитража
  store.py       SQLite: лоты, ряды цен, comps, deals (база сделок), возможности
  comps_io.py    импорт/экспорт comps, загрузка пула для аналитики
  report.py      автономный HTML-отчёт (инлайн-стили)
  demo.py        синтетический рынок для демо-прогона всех стратегий
  sources/
    staraya_moneta.py  магазин (проверено) + аукционы (experimental)
    meshok.py          активные и завершённые лоты, устойчив к смене вёрстки
    sold.py            универсальный импорт сделок: CSV/JSON/HTML-архивы аукционов
scan.py          CLI (все команды)
data/            coins.db, comps_seed.csv, report.html, opportunities.*, price_index.csv
data/examples/   примеры форматов импорта сделок
docs/PLAYBOOK.md методика, экономика, риски, план наполнения базы
tests/           pytest: справочник, нормализация, мешок, сделки, арбитраж
```

## Ограничения, о которых нужно знать

- Демо-comps в `comps_seed.csv` — иллюстрация механики, не рыночные данные;
  в калибровке NGS они не участвуют.
- Вес и металл восстанавливаются по справочнику: для нестандартных и спорных
  типов (например, 5 копеек 1886–1917, где чеканились и медь, и серебро)
  остаются пустыми — осознанно, лучше пусто, чем неверно.
- Мешок не собирается без ваших cookies/прокси — это ограничение доступа, а не кода.
- Аукционный парсер SM и фильтр «завершённых» Мешка написаны устойчиво, но не
  проверены на живой разметке — при первом прогоне сверьте результат с браузером.
- Сбор данных в обход защиты площадки нарушает её пользовательское соглашение.
